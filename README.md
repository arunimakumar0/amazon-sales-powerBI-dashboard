# Amazon Sales & Operations Analytics – Power BI

##  Project Overview

This Power BI project analyzes Amazon sales and operational data to provide insights into sales performance, customer behavior, product performance, order fulfillment, shipping costs, discounts, and seller performance.

The dashboard was designed to help understand key business KPIs and identify trends across products, categories, countries, customers, sellers, payment methods, and order statuses.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Cleaning & Transformation
- Data Visualization
